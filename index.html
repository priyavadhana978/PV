01INTAKE STATION

Feeding the line with Scanner

Scanner is the intake valve — it takes whatever a person types and hands it to your program as a usable value. Run the two gauges below.

nextInt() expected a whole number — no letters.
medallion bay — empty until you cast
IntakeStation.java
import java.util.Scanner;

public class IntakeStation {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Name: ");
        String name = sc.nextLine();

        System.out.print("Age: ");
        int age = sc.nextInt();

        System.out.println(name + " — cleared for line, age " + age + ".");
        sc.close();
    }
}
02ARCHIVE VAULT

Pulling records with BufferedReader

A file is a sealed crate of lines already sitting in storage. readLine() opens it and hands them over one at a time, until there's nothing left.

CRATE #114 — SEALED

Batch accepted: 08:41
Units inspected: 96
Rejects flagged: 3
Batch closed: 09:12

PULLED ONTO THE LINE

PullRecords.java
import java.io.*;

public class PullRecords {
    public static void main(String[] args) {
        try (BufferedReader in = new BufferedReader(new FileReader("batch114.txt"))) {
            String line;
            while ((line = in.readLine()) != null) {
                System.out.println(line);
            }
        } catch (IOException e) {
            System.out.println("Crate could not be opened: " + e.getMessage());
        }
    }
}
03STAMPING PRESS

Punching new records with BufferedWriter

Whatever the press stamps stays stamped — write() plus newLine() is how a result gets punched permanently into a file.

plate is blank — nothing stamped yet
StampRecord.java
import java.io.*;

public class StampRecord {
    public static void main(String[] args) {
        try (BufferedWriter out =
                 new BufferedWriter(new FileWriter("plate.txt", true))) {
            out.write("Unit QA-812 passed inspection");
            out.newLine();
        } catch (IOException e) {
            System.out.println("Press jammed: " + e.getMessage());
        }
    }
}
